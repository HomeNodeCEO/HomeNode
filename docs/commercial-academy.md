# Commercial Academy

Route: `/academy/commercial`, linked from Property Search and retained inside the existing application authentication boundary. The route is lazy loaded; no backend, database, authentication, access or native mobile changes.

The feature contains 10 detailed chapters with 40 reading sections, step-by-step worked examples and 20 ungraded knowledge checks. Each chapter ends with a five-question exam; all answers must be selected before submission reveals the score and explanations for all four choices. The 50 original questions also support a core review set, bookmarks, missed-question review and first-attempt scoring. A direct-cap lab, five-year DCF lab with sensitivity table and formula CSV, interview prompts and primary-source readings remain available. All property inputs and rates are explicitly fictional educational assumptions, not current Dallas market evidence or BBG-endorsed material.

Progress is local to this browser and namespaced by the authenticated user ID (or the application's existing local mode). It is not synchronized across devices. The existing v1 answers and bookmarks are retained; optional readModules and lastModuleId add chapter completion and reading resume without overwriting exam history. Knowledge checks are ungraded and transient. Exam choices are drafts until the complete set is submitted; retakes preserve original first-attempt answers. Invalid/obsolete stored entries are dropped, and storage errors leave a session-only experience with a visible notice. Reset affects only the current account's course state.

NOI in the cases is before reserves; DCF capital and leasing costs are separate. The office model uses end-of-year, unlevered, before-income-tax cash flows and forward Year 6 NOI for an end-of-Year-5 sale. Independent base check: operating PV $2,384,257.12, sale PV $7,188,241.13, value $9,572,498.26. The apartment income bridge produces $800,000 NOI and $12,800,000 at 6.25%.

Validation: `node --experimental-strip-types --test scripts/testCommercialAcademy.mjs`, frontend typecheck and production build. Numeric tests cover the income bridge, terminal-year convention, present value, sensitivity, input bounds and spreadsheet references; progress tests cover retries and corrupt stored data. Source content is under `src/features/academy` and citations are maintained in `reference.ts`.
